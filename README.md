# 용돈 가계부

수입과 지출을 간단히 기록하는 용돈 가계부 웹앱입니다.
HTML/CSS/JS만으로 만들었고, 휴대폰 홈 화면에 설치해서 인터넷 없이도 쓸 수 있는 PWA입니다.

**바로 사용하기:** https://10322-kr.github.io/allowance-ledger/

## 기능

- **월별 합계**: 화면 상단에 그달의 수입, 지출, 잔액(수입 − 지출)을 자동으로 계산해서 보여줍니다.
- **월 이동**: ‹ › 버튼으로 이전 달과 다음 달 내역을 볼 수 있습니다.
- **날짜별 내역 목록**: 내역을 날짜별로 묶어 최신 날짜부터 보여주고, 날짜마다 그날의 합계를 표시합니다.
- **내역 추가**: 수입/지출 구분, 날짜, 금액, 분류(용돈·식비·간식·교통·문구·취미·기타), 메모를 입력해 추가합니다.
  - 다른 달 날짜로 추가하면 그 달로 자동 이동합니다.
  - 추가 후 금액과 메모만 비워져서 연속 입력이 편합니다.
- **내역 삭제**: 각 항목 옆 × 버튼으로 지울 수 있고, 삭제 전에 확인 창이 뜹니다.
- **자동 저장**: 모든 내역은 브라우저의 localStorage에 저장되어 새로고침해도 남아 있습니다.
  - 같은 브라우저의 다른 탭에서 바꾼 내용도 자동으로 반영됩니다.
- **오프라인 사용**: 서비스 워커가 앱 파일을 캐시해서 인터넷 없이도 열립니다.
- **모바일 화면 지원**: 휴대폰 화면 폭에 맞춰 보기 편하게 배치되고, 기기 기본 글꼴을 사용합니다.

> 내역은 기기와 브라우저마다 따로 저장됩니다. PC에서 입력한 내역은 휴대폰에서 보이지 않습니다.
> 브라우저의 사이트 데이터를 지우면 내역도 함께 지워집니다.

## 설치 방법

### 휴대폰 홈 화면에 설치

- **아이폰**: Safari로 위 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 위 주소 열기 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

### PC에서 직접 실행

```bash
git clone https://github.com/10322-kr/allowance-ledger.git
cd allowance-ledger
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.
`index.html`을 더블클릭해서 열어도 화면은 보이지만, 그렇게 열면 서비스 워커(오프라인 기능)가 작동하지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조, PWA·아이폰용 meta 태그, 서비스 워커 등록 |
| `style.css` | 디자인 (밝은 배경, 초록 포인트 색, 모바일 대응) |
| `app.js` | 내역 추가·삭제, localStorage 저장, 월별 합계 계산 |
| `manifest.json` | 앱 이름, 아이콘, 테마 색 등 설치 정보 |
| `service-worker.js` | 파일 캐시와 오프라인 동작 |
| `icons/` | 앱 아이콘 (192px, 512px, 아이폰용 180px) |

파일을 수정한 뒤에는 `service-worker.js`의 `CACHE_VERSION`을 올려야 설치된 앱에 새 파일이 반영됩니다.

## 사용한 프롬프트

이 앱은 Claude Code에게 아래 프롬프트를 순서대로 입력해서 만들었습니다.

1. `git init`
2. 용돈 가계부 웹앱 화면을 HTML/CSS/JS로 만들어줘. 아직 기능은 없어도 돼.
   상단에는 월별 수입과 지출 합계, 중간에는 날짜별 내역 목록, 하단에는 수입/지출을 기록할 수 있는 입력 폼을 배치해 줘.
   밝은 배경에 깔끔한 한글 글꼴을 사용하고, 모바일에서도 보기 편하게 만들어 줘.
   파일은 index.html, style.css, app.js (경로는 모두 상대 경로)로 만들고, 다 만들면 브라우저에서 열어줘.
3. 포인트 색은 초록색이며, 글꼴은 구글 글꼴 연결을 빼고 기기 기본글꼴을 쓰게 바꿔줘. service-worker.js의 캐시버전도 올리고 커밋해서 push해줘
4. (git 사용자 이름과 이메일 설정)
5. 방금 수정한 디자인 파일들 커밋해줘
6. 수입과 지출 금액, 날짜, 내역을 폼에 입력하고 추가 버튼을 누르면 중간의 내역 목록에 추가되게 해줘. 이 데이터는 브라우저의 localStorage에 저장해서 새로고침해도 지워지지 않게 남겨줘.
7. 지금까지 변경사항 커밋해줘
8. localStorage에 저장된 내역들을 바탕으로, 화면 상단에 있는 월별 수입과 지출 합계가 자동으로 계산되어 표시되게 해줘.
9. 내역 목록의 각 항목 옆에 삭제 버튼을 만들어서, 잘못 입력한 내역을 지울 수 있게 해줘. 삭제하면 localStorage 데이터와 월별 합계에도 바로 반영되게 해줘.
10. 커밋해줘
11. 이 폴더를 같은 Wi-Fi의 휴대폰에서 볼 수 있게 python -m http.server로 0.0.0.0:8000에 띄우고, 내 PC의 IP 주소를 알려줘.
12. 서버꺼줘
13. 이 웹앱을 아이폰과 안드로이드 모두 홈 화면에 설치할 수 있는 PWA로 만들어줘.
    - manifest.json: 앱 이름 '용돈 가계부', display standalone, 테마 색 초록
    - 아이콘: 192px, 512px, 아이폰용 180px(apple-touch-icon) PNG 생성
    - service-worker.js: 모든 파일을 캐시해서 인터넷 없이도 열리게
    - index.html에 manifest, 아이폰용 meta 태그, 서비스 워커 등록 추가
    - 경로는 모두 상대 경로로
14. 변환이 완료되면 PC 브라우저에서 F12를 눌러 '애플리케이션(Application)' 탭에 진입한 뒤, Manifest 파일과 Service Worker가 정상적으로 보이는지 점검하고 작업 폴더 내에 3개의 아이콘 파일이 생성되었는지 확인해줘
15. `python -m http.server 8000`
16. 커밋해줘
17. 서버꺼줘
18. GitHub에 공개 저장소 allowance-ledger를 만들어 push하고, GitHub Pages를 main 브랜치 루트로 켜줘. 접속 주소를 알려줘.
19. 응 설치 진행해줘 (GitHub CLI 설치)
20. 승인했어. 이메일은 비공개해줘.
21. 새 코드 줘 (GitHub 로그인 코드 재발급)
22. 전역 git 이메일도 noreply 주소로 바꿔줘
23. README.md에 앱 소개, 기능 목록, 설치 방법, 내가 사용한 프롬프트를 정리해줘
